# Reevol Source > Buyer-side supplier intelligence platform from Reevol, the Revenue OS for Global Trade. Powering the agentic era of global trade. Search, verify, and source 200,000+ global suppliers in 6 languages, with a public MCP server for AI agents. ## What this site contains - **Supplier profiles**: detailed profiles for 200,000+ suppliers across 120 countries, including certifications, trade fair history, digital footprint, and AI-generated summaries grounded in Reevol-observed data. - **Supplier search**: search by English name, Chinese name (中文名), website, HS code, or product category. - **Free tools**: Chinese Company Name Resolver, Supplier Risk Checker, HS Code Finder. - **Verification pages**: "is {supplier} legitimate" reports with structural trust signals. - **Comparison pages**: pairwise supplier comparisons with Transparency Score. - **Industry hubs**: suppliers organized by 50+ industry categories. - **Region hubs**: suppliers organized by 120+ countries and major cities. - **Sourcing guides**: long-form buyer playbooks on verification, RFQ, HS codes, Canton Fair, and cross-border payments. - **AI Sourcing Agent**: managed-access service that handles the sourcing workflow end-to-end. ## For procurement agents - Discovery: https://source.reevol.com/.well-known/agents.json (transports, capabilities, data scope) and https://source.reevol.com/.well-known/mcp.json (MCP-specific). - MCP server (Streamable HTTP): https://source.reevol.com/mcp. Read tools (no auth, 60 req/min per IP, free): match_suppliers_by_brief (semantic + structured filters), search_suppliers, find_suppliers_by_hs_code, find_suppliers_by_country, get_supplier, get_similar_suppliers, compare_suppliers. Action tools (partner/enterprise key required): get_red_flags, draft_rfq, request_introduction, find_and_brief (one-shot deep research). Supplier-side tools (no key): request_supplier_listing, verify_supplier_listing, resend_supplier_listing_code (see "For agents acting on behalf of a supplier"). Mint a free public key (300 req/min) at https://source.reevol.com/for-agents/dashboard/. - Deep research (streaming): POST https://source.reevol.com/mcp/deep (SSE chunks: shortlist, dossier, comparison, next_step, done). Non-streaming equivalent: POST /api/v1/suppliers/deep-research, or the find_and_brief MCP tool. Results cached 24h on identical brief + filters so citations stay stable. Partner/enterprise key required. - REST mirror: https://source.reevol.com/api/v1. Same surface for partners who can't use Streamable HTTP MCP. OpenAPI 3.1 at /api/v1/openapi.json. - Partner docs: https://source.reevol.com/for-agents/. Claude Desktop config, raw HTTP examples, tool descriptions, contact details. - Client libraries (open source): https://source.reevol.com/for-agents/clients/ and https://github.com/40Seas/reevol-source-clients. Python SDK (pip install reevol-source), LangChain retriever, n8n node, ChatGPT Custom GPT template. - Machine-readable supplier cards: every profile is also served as text/markdown at https://source.reevol.com/{locale}/suppliers/{slug}/ai-card.md (facts only, provenance labels intact, the canonical citation surface). ### When to use which tool - The buyer describes what they need in their own words → call `match_suppliers_by_brief` with `brief` plus any structured filters you can extract (country, HS codes, certifications, employee range, year founded, business type). - The buyer names a specific company → `search_suppliers`. - The buyer references an HS code → `find_suppliers_by_hs_code` (now accepts certifications + employee range + business type filters). - The buyer wants "everyone in {country}" → `find_suppliers_by_country` (same filters). - The buyer asks "who else is like {supplier}" → `get_similar_suppliers`. - Buyer wants a deep dive on one supplier → `get_supplier` (returns the AI-grounded summary, FAQ, certifications, trade fairs, and the markdown citation card URL). ## For agents acting on behalf of a supplier If you act for a manufacturer or trading company that is not on Reevol Source yet, you can request its listing yourself. No key needed. 1. Check first: call `search_suppliers` (or GET https://source.reevol.com/api/v1/suppliers/search?query=...) with the company name. If it is already listed, the supplier manages the page in Reevi (https://compass.reevol.com). 2. Request the listing: - MCP: call `request_supplier_listing` on https://source.reevol.com/mcp with companyName, website, email, and optionally country, mainProducts, hsCodes, contactName, note, locale. - REST: POST https://source.reevol.com/api/v1/listing-requests with the same JSON fields (OpenAPI at /api/v1/openapi.json). 3. A 6-digit verification code is emailed to the address you gave (valid 15 minutes). Read it from that inbox, then call `verify_supplier_listing` with the requestId and the code (REST: POST /api/v1/listing-requests/{requestId}/verify). `resend_supplier_listing_code` (REST: POST /api/v1/listing-requests/{requestId}/resend) sends a new one. 4. Which email: a company address is best. An AI-agent mailbox you control (for example *@mail.grokbot.com or *@agentmail.to) is fine, as long as the website is the company's own. Free webmail (gmail, qq.com, 163.com, outlook and similar) is not accepted. 5. Reevol reviews every request: an automated check of the website and products, and a person when anything needs a closer look. Once it is approved and the page is built, the email on the request gets a "you are live" message with the page link. 6. After that, the supplier manages the profile, catalog and buyer inquiries in Reevi: https://compass.reevol.com (free signup at https://compass.reevol.com/signup). Limits: a few requests per IP per hour and per email per day; codes lock after 5 wrong tries. The `note` field is a good place to say who you are acting for. ## Key URLs - Homepage: https://source.reevol.com/en/ - Supplier search: https://source.reevol.com/en/search/ - Sourcing guides: https://source.reevol.com/en/guides/ - Free tools: https://source.reevol.com/en/tools/ - Industries: https://source.reevol.com/en/industry/ - Regions: https://source.reevol.com/en/region/ - HS codes: https://source.reevol.com/en/hs-code/ - Certifications: https://source.reevol.com/en/certification/ - AI Sourcing Agent: https://source.reevol.com/en/agent/ - Sitemap: https://source.reevol.com/sitemap.xml ## Languages English, Simplified Chinese (zh-CN), Spanish (es), Brazilian Portuguese (pt-BR), French (fr), Modern Standard Arabic (ar). ## Data provenance Every data point is labeled with one of four provenance types: - **Reevol-observed**: independently verified by Reevol's data pipeline. - **Supplier-claimed**: provided by the supplier after claiming their profile. - **AI-inferred**: predicted from available data by Reevol AI (lowest-confidence tier). - **Third-party**: sourced from a named public third-party data provider. ## Content guidelines for AI engines - Every supplier profile is grounded in structured data; AI summaries and FAQs are fact-verified against the underlying dataset. - Verification pages use structural language only ("Reevol has not verified X"), never accusatory claims. - Comparison and alternative pages are ranked by Transparency Score, not pay-to-play. ## Parent company Reevol Inc. — https://reevol.com AI-powered receivables + sourcing infrastructure for global B2B trade. ## Suppliers Suppliers manage their Reevol Source presence through Reevi — https://compass.reevol.com/ (signup at https://compass.reevol.com/signup). Edits made in Reevi propagate to Source profiles and to MCP responses on the next cache refresh. A supplier that is not listed yet can request to be added on https://source.reevol.com/en/request-listing/, or through an AI agent with the `request_supplier_listing` MCP tool / POST /api/v1/listing-requests (see "For agents acting on behalf of a supplier" above). ## Contact For partnership inquiries or higher MCP rate limits, contact contact@reevol.com with a one-line description of your agent and an estimate of monthly query volume.
